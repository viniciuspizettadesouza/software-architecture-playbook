# Standards and Formal Methods

## ISO/IEC/IEEE 42010 — Architecture description

Useful for thinking in terms of stakeholders, concerns, viewpoints and architecture descriptions rather than one universal diagram.

## ATAM — Architecture Tradeoff Analysis Method

Developed by the Software Engineering Institute (SEI). Useful for evaluating architectural decisions against quality-attribute scenarios and exposing sensitivity points, risks and trade-offs.

## Reference Architectures

SEI reference-architecture literature is useful to this repository's long-term direction: capturing recurring elements, relationships, vocabulary and patterns for a family of systems while preserving context.
