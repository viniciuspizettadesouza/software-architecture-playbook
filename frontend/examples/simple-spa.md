# Example — Simple SPA

Suitable for a small interactive client-side product.

```text
React
TypeScript
Vite
Vitest
Testing Library
ESLint
Prettier
```

Add React Router only if URL navigation becomes meaningful. Add Zod only at real runtime boundaries. Add Playwright only for critical browser journeys.

This example intentionally has no global-state library, no server-state library and no monorepo.
