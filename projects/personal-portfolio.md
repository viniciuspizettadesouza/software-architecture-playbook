# Personal Portfolio

Focused single-page professional portfolio deployed as static assets.

## Interesting architecture decision

React, TypeScript and Vite are sufficient for the product. There is no router, server rendering or backend without a requirement for one.

Related concepts: [Proportional Architecture](../concepts/proportional-architecture.md), [KISS](../concepts/kiss.md) and [YAGNI](../concepts/yagni.md).

## Trade-off to remember

This structure remains appropriate while the product is a focused static page. Meaningful navigation or dynamic server responsibilities would trigger reassessment.
