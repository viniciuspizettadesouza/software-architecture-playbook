# Project Examples

These notes preserve interesting decisions and lessons from real projects. They are examples, not rankings or proof that a decision belongs everywhere.

- [MercadoZetta](mercadozetta.md): generated contracts, persistence mapping, ADRs and layered CI.
- [Auth Lab](auth-lab.md): feature adapters and stable authentication contracts.
- [Engineering Case Studies](engineering-case-studies.md): incremental modularity, explicit boundaries and static-first delivery.
- [Habemus Papam](habemus-papam.md): an independent core shared by several delivery mechanisms.
- [Codex Reset Tracker](codex-reset-tracker.md): trust boundaries and data minimization.
- [Challenge Portfolio](challenge-portfolio.md): preserved code separated from maintained demos.
- [TCC Project](tcc-project.md): traceable and reproducible analytical results.
- [Personal Portfolio](personal-portfolio.md): architecture proportional to a static single-page product.
- [Portugal Prático](portugal-pratico.md): content freshness modeled as an executable domain rule.
