# Proportional Architecture

## What it means

Architecture complexity should be proportional to current requirements, risks and expected change.

## Why it matters

A static site, prototype and multitenant marketplace do not need the same layers, infrastructure or operational mechanisms.

## Decision questions

1. What concrete problem does this addition solve now?
2. What complexity does it introduce?
3. What happens if it is postponed?
4. What signal would justify revisiting the decision?

## Don't overdo it

Minimalism should not ignore material security, reliability or migration risks.
